# Fix ZT source — 2026-06-14

## Symptôme
Onglet « Sources ZT » de l'embed download affiche « Aucune source ZT disponible ».
L'API `apis.wavewatch.top/zt.php?_route=api&type=movie&id=…` retourne systématiquement
`totalLinks: 0` et le message « Aucun lien trouvé pour ce titre sur zone-telechargement.org ».

## Cause racine
Le site `zone-telechargement.org` a refondu son CMS début 2026. URLs et HTML changés.

| Ancien (DLE legacy)                          | Nouveau (2026)                                   |
| -------------------------------------------- | ------------------------------------------------ |
| `/index.php?do=search&subaction=search&story=Q` | `/?p=films&search=Q` (sections : `films`, `series`, `mangas`, `jeux`, `musiques`, `ebooks`, `logiciels`, `autres-videos`) |
| `/film-gratuit/12345-slug.html`              | `/?p=film&id=12345-slug` (kinds : `film`, `serie`, `manga`, `jeu`, `musique`, `ebook`, `logiciel`, `autre-video`, `mobile`) |
| Bandeau « Qualité X \| LANG »               | `<strong><u>Qualité</u> :</strong> X<br><strong><u>Langue</u> :</strong> Y<br>` |
| `<div class="postinfo">` avec `btnToLink` + `zoneurs.net/?url=BASE64` | `<div class="postinfo">` avec `<div font-weight:bold>HostName</div>` + `<a href="https://dl-protect.link/HASH?fn=BASE64&rl=aN">Télécharger</a>` |
| `▶ Regarder en Streaming`                    | `<h2>Liens De Téléchargement :</h2>` puis `<h2>Liens De Streaming :</h2>` |

Le scraper `/app/zt.php` cherchait toujours les anciens patterns → 0 hit.

## Correction appliquée à `/app/zt.php`
1. **`scrape_listing()`** — match du nouveau pattern `?p=<kind>&id=<id>-<slug>` (relatif ou absolu, avec ou sans `&amp;`).
2. **`zt_search_url()` / `zt_search()`** — accepte un paramètre `$type` et cible la bonne section (`?p=films`, `?p=series`, …).
3. **`zt_search_section()`** — nouvelle fonction qui map type API → section URL.
4. **`type_to_categories()`** — retourne les nouveaux « kinds » singuliers (`['film']`, `['serie']`, …) au lieu des slugs DLE.
5. **`category_from_url()`** — extrait le `kind` depuis `?p=<kind>&id=`.
6. **`scrape_detail_html()`** — réécriture quasi-complète :
   - Quality/Lang/Size depuis `<strong><u>…</u> :</strong> …<br>` (films) **et** depuis le bandeau `font-size:18px;color:red` (séries).
   - Filename depuis `<center><font color="red">FILENAME (SIZE)</font></center>`.
   - Liens : découpage par `<h2>Liens De Téléchargement :</h2>` / `<h2>Liens De Streaming :</h2>`,
     puis parsing séquentiel `<div font-weight:bold>HostName</div>` + `<a href="dl-protect.link/…">…</a>`.
   - `protection = "dl-protect"` (les URLs ne sont plus décodables côté serveur,
     elles passent par un captcha/redirector → c'est le comportement légitime du site).
   - Reconnaît « N Episodes \| Saison Y » pour les pages séries.
7. **Meta** — regex tolérante aux valeurs contenant `<a>…</a>` (Réalisateur, Acteurs, Genres),
   ajout des labels `Nationalité`, `Réalisateur(s)`, `Année de production`, `Taille du fichier`,
   `Taille d'un episode`, `Critiques Spectateurs`, `Qualité`.

## Déploiement
Le fichier `/app/zt.php` doit être uploadé sur le serveur `apis.wavewatch.top`
(remplacer le `zt.php` existant à la racine).

Une fois déployé :
- Pas besoin de purger le cache Mongo `zt_cache` côté Next.js : le proxy ne cache
  PAS les réponses vides (cf. `frontend/app/api/v1/zt-proxy/route.ts` ligne 132–145).
- Les liens retournés sont des URLs `dl-protect.link` (comportement normal du site
  2026 — ils étaient en `zoneurs.net` avant). Le champ `protection: "dl-protect"`
  informe le front que l'utilisateur devra passer par la page intermédiaire.
